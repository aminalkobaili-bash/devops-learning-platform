## Три скрипта

| Скрипт | Что делает |
|---|---|
| `fs-generator` | дерево папок и файлов до 100 KB по шаблону имён в заданном каталоге |
| `disk-filler` | файлы до 100 MB в `/tmp`, `/var/tmp`, `$HOME` — нагрузка на диск для графиков Grafana |
| `fs-cleaner` ⚠️ | удаление созданного: по логу, по интервалу времени, по маске даты в имени |

```bash
./main.sh /opt/test 4 az 5 az.az 3kb     # fs-generator: 4 папки, по 5 файлов по 3 KB
./main.sh az az.az 5Mb                   # disk-filler
./main.sh 1                              # fs-cleaner: по логу
```

## Создание файла нужного размера

| Способ | Что происходит | Скорость |
|---|---|---|
| `truncate -s 3K file` | создаёт **разреженный** файл: размер 3K, а блоков на диске почти не занято | мгновенно |
| `dd if=/dev/zero of=file bs=1M count=5` | реально записывает 5 МБ нулей | зависит от диска |
| `fallocate -l 5M file` | резервирует блоки без записи данных | мгновенно |

- `fs-generator` использует `truncate` — диск не заполняется, `ls -l` покажет 3K, а `du` — почти 0.
- `disk-filler` использует `dd` — данные реально пишутся, поэтому свободное место падает и это видно в Grafana: `custom_disk_free` от ~11.75 до ~10.5 млн KB (≈1.2 GB).

```bash
ls -lh file     # логический размер
du -h file      # реально занято на диске
```

## Защита от заполнения диска

```bash
check_disk_space() {
    local free=$(df / --output=avail | tail -1)
    if (( free < 1048576 )); then
        echo "Less than 1GB free space. Script stopped."
        exit 1
    fi
}
```

- `df --output=avail` — только колонка свободного места, в **КиБ**; `tail -1` убирает заголовок.
- `1048576` КиБ = 1 GiB.
- `(( … ))` — арифметическое сравнение в bash.

> Проверяется только `/`. Если `/tmp` или `$HOME` смонтированы на отдельные разделы, проверка смотрит не туда. Точнее: `df "$target_dir" --output=avail`.

## Разбор параметров строками bash

```bash
file_pattern="az.az"
name=${file_pattern%.*}     # az   — удалить самое короткое .* с конца
ext=${file_pattern#*.}      # az   — удалить самое короткое *. с начала

file_size="3kb"
size=${file_size%kb}        # 3
```

| Подстановка | Что удаляет |
|---|---|
| `${var%pattern}` | кратчайшее совпадение **с конца** |
| `${var%%pattern}` | длиннейшее с конца |
| `${var#pattern}` | кратчайшее **с начала** |
| `${var##pattern}` | длиннейшее с начала |
| `${var:0:1}` | подстрока: первый символ |
| `${var: -1}` | последний символ (пробел обязателен) |

Пример: `f=archive.tar.gz` → `${f%.*}` = `archive.tar`, `${f%%.*}` = `archive`.

## Генерация имён и найденный недочёт

```bash
generate_name() {
    local letters=$1 index=$2 name=""
    for ((i=0; i<index+4; i++)); do
        name+=${letters:0:1}
    done
    name=${name:0:-1}${letters: -1}
    echo "${name}_$(date +%d%m%y)"
}
```

Проверка:

| Вызов | Результат |
|---|---|
| `generate_name az 1` | `aaaaz_081126` |
| `generate_name abc 1` | `aaaac_081126` — буква `b` потеряна |
| `generate_name abc 3` | `aaaaaac_081126` |

Имя собирается только из первой и последней буквы шаблона — средние не используются (недочёт 5 из README).

## Лог созданных файлов

```bash
echo "$path $(date '+%d.%m.%y') $size" >> "$log_file"
```

Режим 1 `fs-cleaner` читает лог **с конца** (`tac`) — сначала удаляются файлы, потом пустые папки, в которых они лежали.

## ⚠️ Опасная очистка

Режимы 2 и 3 `fs-cleaner`:

```bash
find /tmp /var/tmp "$HOME" -name "*_${mask}*" -exec rm -rf {} +
```

Удаляет **всё** в домашнем каталоге и `/tmp`, что совпало с маской `*_081126*`, — включая чужие файлы с датой в имени. Вывод ошибок скрыт в `2>/dev/null`, подтверждения нет.

Безопасная практика для скриптов удаления:

1. Сначала показать, что будет удалено: тот же `find` с `-print` вместо `-exec rm`.
2. Ограничить пути каталогами, которые создал генератор (из лога).
3. Спросить подтверждение или требовать флаг `--force`.
4. Использовать `-delete` у `find` вместо `-exec rm -rf` для файлов — он не рекурсивный.

## find -newermt: по времени изменения

```bash
find /tmp -newermt "2026-11-08 10:00" ! -newermt "2026-11-08 11:00"
```

Файлы, изменённые между 10:00 и 11:00. `-newermt` — «новее, чем указанная дата» (m — mtime, t — дата строкой).
