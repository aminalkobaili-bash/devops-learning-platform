## IPv4-адрес и маска

IPv4-адрес — 32 бита, записанные четырьмя числами 0–255: `10.10.0.1`. Маска делит адрес на две части:

- **сеть** — биты, где в маске `1`;
- **хост** — биты, где в маске `0`.

| Запись | Пример |
|---|---|
| CIDR (префикс) | `/18` — первые 18 бит — сеть |
| десятичная маска | `255.255.192.0` |
| двоичная маска | `11111111.11111111.11000000.00000000` |

Перевод: `/28` = 28 единиц = `11111111.11111111.11111111.11110000` = `255.255.255.240`. Последний октет: `11110000` = 128 + 64 + 32 + 16 = 240.

| Префикс | Маска | Адресов | Хостов |
|---|---|---|---|
| `/8` | `255.0.0.0` | 16 777 216 | 16 777 214 |
| `/16` | `255.255.0.0` | 65 536 | 65 534 |
| `/18` | `255.255.192.0` | 16 384 | 16 382 |
| `/24` | `255.255.255.0` | 256 | 254 |
| `/26` | `255.255.255.192` | 64 | 62 |
| `/28` | `255.255.255.240` | 16 | 14 |
| `/30` | `255.255.255.252` | 4 | 2 — для связи двух роутеров |

Формула: адресов `2^(32 − префикс)`, хостов — на 2 меньше.

## Сеть, broadcast, диапазон хостов

| Адрес | Как получить | Можно назначить хосту? |
|---|---|---|
| адрес сети | хостовые биты = 0 | нет |
| broadcast | хостовые биты = 1 | нет |
| хосты | всё между ними | да |

Пример из проекта — `10.10.0.0/18`:

- маска `255.255.192.0`, в третьем октете 2 сетевых бита → блоки по 64: 0, 64, 128, 192;
- сеть `10.10.0.0`, broadcast `10.10.63.255`;
- хосты `10.10.0.1 – 10.10.63.254`.

Поэтому адреса `10.10.0.2`, `10.10.10.10` и даже `10.10.1.255` годятся для хостов этой сети: `10.10.1.255` выглядит как broadcast, но в `/18` он — обычный адрес.

### Как найти адрес сети вручную

`192.167.38.54/13`: маска `/13` = `255.248.0.0`. Во втором октете 5 сетевых бит → блоки по 8. `167 / 8 = 20.875` → начало блока `20 × 8 = 160`. Сеть — `192.160.0.0`.

`12.167.38.4/23`: маска `255.255.254.0`, в третьем октете блоки по 2. 38 — чётное → сеть `12.167.38.0`, broadcast `12.167.39.255`, хосты `12.167.38.1 – 12.167.39.254`.

## Частные сети (RFC 1918)

Не маршрутизируются в интернете — используются внутри организаций и за NAT:

| Диапазон | Префикс |
|---|---|
| `10.0.0.0 – 10.255.255.255` | `10.0.0.0/8` |
| `172.16.0.0 – 172.31.255.255` | `172.16.0.0/12` |
| `192.168.0.0 – 192.168.255.255` | `192.168.0.0/16` |

Все адреса проекта — частные. `172.24.116.8/12` из стенда ws2 входит в `172.16.0.0/12`.

Ещё два особых диапазона: `127.0.0.0/8` — loopback (сам хост), `169.254.0.0/16` — link-local (адрес, который хост назначает себе сам, если DHCP не ответил).

## Проверка: в одной ли сети два адреса

Два хоста общаются напрямую, только если их адреса в одной сети при их масках. Иначе нужен роутер.

| Хост A | Хост B | Одна сеть? |
|---|---|---|
| `10.20.0.10/26` | `10.20.0.20/26` | да: обе в `10.20.0.0 – 10.20.0.63` |
| `10.20.0.10/26` | `10.20.0.70/26` | нет: `.70` — в следующем блоке `10.20.0.64/26` |
| `10.10.0.2/18` | `10.20.0.10/26` | нет — нужна маршрутизация (модуль 04) |

## ipcalc

```bash
sudo apt install ipcalc
ipcalc 10.10.0.0/18
```

Выводит маску, адрес сети, broadcast, первый и последний хост, количество хостов, класс и признак частной сети.
