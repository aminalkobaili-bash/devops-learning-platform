## Пакеты: apt

Ubuntu ставит программы из `.deb`-пакетов, которые лежат в репозиториях. Список репозиториев — `/etc/apt/sources.list` и `/etc/apt/sources.list.d/`.

| Команда | Что делает |
|---|---|
| `sudo apt update` | скачивает **списки** пакетов из репозиториев. Ничего не устанавливает |
| `sudo apt upgrade` | обновляет установленные пакеты до версий из списков |
| `sudo apt full-upgrade` | то же, но может удалять пакеты ради разрешения зависимостей |
| `sudo apt install nginx` | установить пакет с зависимостями |
| `sudo apt remove nginx` | удалить пакет, конфиги оставить |
| `sudo apt purge nginx` | удалить вместе с конфигами |
| `sudo apt autoremove` | удалить зависимости, которые больше никому не нужны |
| `apt list --upgradable` | что можно обновить |
| `apt show nginx` | описание и версия пакета |

```bash
sudo apt update && sudo apt upgrade -y
```

- `&&` — вторая команда выполнится, только если первая завершилась успешно.
- `-y` — автоматически отвечать «да». Удобно в скриптах, но в рабочей системе лучше видеть, что будет обновлено.

> `apt upgrade` без `apt update` обновляет до версий из **старых** списков — то есть часто ничего не делает. Порядок всегда: сначала `update`, потом `upgrade`.

Проверка из проекта: после обновления повторный `apt update` пишет `All packages are up to date`.

### apt и apt-get

`apt` — удобная команда для человека (прогресс-бар, цвет). `apt-get` — стабильный интерфейс для скриптов: его вывод не меняется между версиями. В Dockerfile и CI пишут `apt-get`.

## Время

Точное время на сервере критично:

- метки в логах — по ним сопоставляют события на разных серверах;
- TLS-сертификаты проверяются по дате;
- cron запускает задачи по часам;
- распределённые системы и базы данных сравнивают время транзакций.

### timedatectl

```bash
timedatectl                              # текущее время, пояс, статус NTP
sudo timedatectl set-timezone Europe/Moscow
sudo timedatectl set-ntp true            # включить синхронизацию
timedatectl show | grep NTPSynchronized  # NTPSynchronized=yes
```

| Строка вывода | Значение |
|---|---|
| `Local time` | время в выбранном поясе |
| `Universal time` | UTC |
| `RTC time` | аппаратные часы |
| `Time zone` | пояс, например `Europe/Moscow (MSK, +0300)` |
| `NTP service: active` | служба синхронизации запущена |
| `System clock synchronized: yes` | время уже сверено с NTP-сервером |

### NTP

Network Time Protocol — протокол синхронизации часов с серверами точного времени (UDP-порт 123). В Ubuntu Server по умолчанию работает лёгкий клиент `systemd-timesyncd`; сервера задаются в `/etc/systemd/timesyncd.conf`. Для серверов с повышенными требованиями ставят `chrony`.

> Часовой пояс не влияет на синхронизацию: системные часы всегда идут в UTC, пояс — только способ отображения.

```bash
timedatectl timesync-status   # с каким сервером синхронизировались, смещение
```
