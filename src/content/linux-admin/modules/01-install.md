## Что было сделано

VirtualBox VM: 2 CPU, 2 GB RAM, диск 25 GB, без EFI. Ubuntu Server 20.04.6 LTS (ядро 5.4), OpenSSH поставлен прямо в установщике.

| Раздел | Размер | Что на нём |
|---|---|---|
| `sda1` | 1 MB | BIOS boot (служебный, для GRUB на GPT без EFI) |
| `sda2` | 2 GB | `/boot`, ext4 |
| `sda3` | остаток | LVM: группа `ubuntu-vg`, том `ubuntu-lv` 12 GB → `/`, ext4 |

## Таблица разделов: MBR и GPT

| | MBR | GPT |
|---|---|---|
| Макс. размер диска | 2 ТБ | практически без ограничений |
| Разделов | 4 основных (или расширенный + логические) | 128 по умолчанию |
| Резервная копия таблицы | нет | есть, в конце диска |
| Загрузка | BIOS | UEFI; с BIOS — через маленький раздел `bios_grub` |

Установщик Ubuntu по умолчанию размечает диск в GPT.

## Зачем отдельный /boot

Загрузчик GRUB должен прочитать ядро и initramfs **до** того, как поднимется LVM. Поэтому `/boot` кладут на обычный раздел, а всё остальное — в LVM.

## LVM — логические тома

Три уровня абстракции:

| Уровень | Сокращение | Что это | Команда просмотра |
|---|---|---|---|
| Physical Volume | PV | раздел или диск, отданный LVM (`/dev/sda3`) | `pvs` |
| Volume Group | VG | пул из одного или нескольких PV (`ubuntu-vg`) | `vgs` |
| Logical Volume | LV | «виртуальный раздел» из пула, на нём ФС (`ubuntu-lv`) | `lvs` |

Зачем:

- **Расширение без переразметки**: добавили диск → `vgextend`, затем `lvextend -r` увеличит том и файловую систему.
- **Снапшоты** тома перед рискованными изменениями.
- Том может занимать несколько физических дисков.

```bash
sudo lvextend -l +100%FREE -r /dev/ubuntu-vg/ubuntu-lv
```

> Установщик Ubuntu отдаёт под `/` не всё место в VG — так и получилось 12 GB из ~23 GB. Свободное место в группе видно в `vgs` (колонка `VFree`); команда выше забирает его целиком, `-r` сразу расширяет ext4.

Путь к тому: `/dev/ubuntu-vg/ubuntu-lv` или `/dev/mapper/ubuntu--vg-ubuntu--lv` (в имени для mapper дефис удваивается).

## ext4

Журналируемая ФС по умолчанию в Ubuntu. Журнал защищает структуру ФС при внезапном отключении питания. Онлайн-расширение поддерживается, онлайн-уменьшение — нет.

## Посмотреть разметку

```bash
lsblk            # дерево: диск → разделы → LVM-тома, точки монтирования
sudo fdisk -l    # таблица разделов, размеры в секторах
df -Th           # смонтированные ФС, их тип и заполнение
```
